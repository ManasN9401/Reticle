# HyperParallel Specialized Skills Guide

HyperParallel empowers agents to perform specialized tasks using pre-configured, production-grade instructions known as "skills." These skills provide strict methodological constraints, standard operating procedures, and automated tooling pathways to ensure agents operate at the highest possible quality.

Skills are stored in the global `skills/` directory at the root of the project.

## Available Core Skills

### 1. OSINT Investigation (`osint-investigation`)

The OSINT Investigation skill equips agents to act as expert open-source intelligence analysts. It is designed to gather digital footprints, map network topology, and extract metadata without triggering active intrusion alerts.

- **Core Principle:** Passive reconnaissance only. Agents are strictly forbidden from running active exploits or vulnerability scanners without explicit user permission.
- **Dynamic Tooling:** Agents use `uv pip install --system` or `uv tool install` to rapidly provision industry-standard tools at runtime.
- **Production Toolkit:**
  - `maigret`: Used for username enumeration across 3,000+ websites.
  - `spiderfoot`: Automated recon tool for IPs, domains, and emails.
  - `photon`: Ultra-fast web crawler for extracting targets.
  - `metagoofil`: Extracts metadata from public documents (PDF, DOCX, etc.).
  - `theHarvester`: Gathers emails and subdomains via search engines.
- **API Dependencies:** Agents are instructed to gracefully degrade if API keys (e.g., `SHODAN_API_KEY`) are missing, relying solely on keyless modules while warning the user.

### 2. Data Analytics & Statistics (`data-analytics-stats`)

This skill enforces rigorous data science principles, preventing LLM arithmetic hallucination by forcing empirical computation via Python.

- **The Stack:** Agents are required to install and utilize `pandas`, `numpy`, `scipy`, `statsmodels`, and `scikit-learn`.
- **Performance:** Enforces the use of vectorized operations over standard Python `for` loops.
- **Statistical Rigor:** 
  - Prevents blind application of models. Agents must verify underlying statistical assumptions (e.g., Shapiro-Wilk for normality, Levene's for variance) before applying Parametric tests like T-tests or ANOVA.
  - Non-parametric fallbacks are automatically applied if assumptions fail.
- **Reproducibility:** Requires explicit random seed setting (`np.random.seed(42)`) and standardized data cleaning pipelines (handling missing values, data type coercion).

### 3. Academic & Research Writing (`academic-writing`)

This skill guarantees that all technical documentation, research reports, and analysis summaries generated by the agents meet top-tier international publishing standards.

- **Formatting Standards:** Adheres to structural templates used by Harvard, MIT, and Oxford (e.g., structured abstracts, objective tone, and Author-Date citation styles).
- **Citation Integrity:** Strictly forbids hallucinated citations. If an agent does not know the source, it must insert `[Citation Needed]`.
- **Industry AI Lab Standards (Google / Anthropic / OpenAI):**
  - **Transparency:** Agents must disclose their own use in the methodology section.
  - **Limitations & Impacts:** Mandatory inclusion of a "Limitations" section (discussing edge cases/biases) and "Broader Impacts" (societal/ethical considerations).
  - **Model Cards:** Enforces structured "Model Card" generation when documenting new algorithms or systems.

## Adding New Skills

You can add new skills at any time to extend the capabilities of the agents.

1. Create a new directory in `d:\HyperParallel\skills\`.
2. Inside the new directory, create a `SKILL.md` file. Define the skill's methodology, constraints, and instructions in this markdown file.
3. **CRITICAL:** Create a `<skill_name>.yaml` file directly in the `skills/` root directory (e.g. `skills/osint-investigation.yaml`). This file is strictly required by the HyperParallel registry to provision the Python environment with necessary dependencies.
   ```yaml
   id: "skill-id"
   name: "Skill Name"
   version: "1.0.0"
   description: "Short description"
   dependencies:
     - "package_a"
     - "package_b"
   env_vars: []
   ```
4. Agents will automatically read the `.yaml` file to provision their environment, and the `SKILL.md` file to enforce their methodology constraints.
