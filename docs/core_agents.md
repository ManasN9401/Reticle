# Core agents

The compiler uses architect-agent to propose a DAG, scaffolder-agent to serialize definitions, coder-agent to generate small SDK entrypoints, and writer-agent to aggregate explicit file maps. Writer is not a prose-authoring model. Hermes/Quant/OSINT/Browser generator entrypoints share the tested generator implementation.

Task specialists include DevOps, ML, frontend, RAG and LaTeX/writing. Their definitions use the common manifest schema and shared worker SDK. Skills are read explicitly for configured specialists/generated workers. A configured dependency or capability is not proof that a cloud account, GPU or external service is available.

HitL is a runtime-owned approval node. It waits for a person for as long as it takes: an approval request does not expire and the node is not subject to the task deadline that bounds other workers, so a decision made hours later is honoured. Only killing the run ends the wait. Every attempt writes a new request with its own identity and a decision is bound to that request's content hash, so an old decision still cannot authorize a retry or a changed plan. Studio's approval screen presents a plan rather than the request file: the goal, the previous step's result (its summary and the plan documents it wrote, rendered as readable text), the steps that will run after approval grouped by what can run in parallel with each step's agent description and permissions, and the whole workflow as a collapsed outline. The exact request the decision is bound to stays available as "Raw request". The request file itself opens with the goal and the input text quoted as readable lines, followed by the exact JSON. When the node starts waiting, Studio shows a toast, and, if Studio is in the background, a system notification, a taskbar flash, and a click-through to the review. Graphify invokes a preinstalled CLI with a deadline and fails if no valid report is produced. It does not install tools globally during execution.

See the current specifications and audit repair status for supported behavior and limits.
