# Session review reminder

The accompanying shell script counts messages and emits a reminder. It does not automatically extract, validate, approve or save learned skills, and Reticle does not invoke it automatically. Configure it explicitly in a compatible host if desired.

For a proposed lesson, record the source failure, scope, supporting evidence and a regression test. Remove private content and credentials. Review and version the proposal before promotion; preserve a rollback path. A model's assertion is not evidence that learning was completed.

Only options actually read by the reminder script affect its behavior. Extraction/approval options in older configurations were placeholders, not implemented automation.
